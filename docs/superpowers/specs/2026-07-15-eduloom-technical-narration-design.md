# EduLoom 401 秒技术型演示口播升级设计

## 一、目标与受众

将现有 6 分 41 秒（401 秒）项目演示口播升级为面向算法岗 HR、技术导师和技术面试官的作品介绍。终稿必须同时做到：

- 保留 EduLoom 的产品定位、主要功能和完整演示路径；
- 明确展示算法理解、Agent 编排能力和生产级工程实现；
- 使用论文作为方法论锚点，但不虚构完整论文复现、基准结果或线上指标；
- 严格沿用现有 00:00–06:41 时间轴，避免要求重新剪辑主要画面；
- 采用自然口语表达，技术密度高但不写成论文摘要。

## 二、叙事方案

采用“双主线技术叙事”：以产品演示作为明线，以“三层记忆”和“DAG 式 Agent 编排”作为贯穿全片的技术暗线。产品价值约占 55%，算法与工程约占 45%；二者在同一画面段落内融合，不设置割裂的独立论文综述。

全片核心技术标签为：

> 三层记忆 + 双阶段画像更新 + DAG 式 Agent 编排

## 四、算法与架构口径

### 4.1 三层记忆

1. **工作记忆**：通过 LangGraph Checkpoint 持久化会话状态，支撑多轮对话连续性。
2. **知识记忆**：课程资料按内容类型分块并生成稠密向量，在 SurrealDB 中执行余弦语义检索；来源洞察与学习笔记也可进入知识上下文。
3. **学习者长期记忆**：采用六维结构化画像，不将用户压缩为单一、不可解释的用户向量。每条事实保存置信度、来源、创建时间和更新时间，可查看、修正和审计。

该设计明确区分两类问题：知识相关性适合使用向量相似度计算；学习目标、认知偏好和易错点则更适合使用可解释的结构化事实表示。

### 4.2 双阶段画像更新

每轮聊天完成后，系统以 fire-and-forget 方式提交后台画像任务，不阻塞聊天热路径：

1. `extract_facts` 从近期会话窗口抽取六个维度的候选学习事实；
2. `reconcile` 将候选事实与现有画像对齐，通过 `ADD`、`UPDATE`、`DELETE`、`NOOP` 四类操作处理新增、修订、遗忘和无变化情况。

该流程借鉴 Mem0 的动态事实抽取与记忆整合范式，但不宣称完整复现 Mem0。结构化输出通过 Pydantic 校验；畸形输出终止当轮更新，瞬时故障由后台队列最多重试五次并采用指数抖动退避。

### 4.3 DAG 式 Agent 编排

系统采用控制平面与执行平面分离的分层结构：

- `LearningCoordinator` 负责加载课程内容、学习画像、路径状态和已有资源；
- `PathPlanner` 规划分步学习目标；
- `ResourcePusher` 将已完成资源匹配到学习步骤，并标记资源缺口；
- `AssessmentAnalyst` 综合画像、路径进度和练习证据形成多维评估；
- `TutorAgent` 优先回答问题和推荐已有资源，仅在资源不足且用户明确需要时建议生成；
- 报告、测验、导图、课件和视频生成器承担角色化的专职任务。

复杂检索遵循“规划—并行执行—证据聚合”流程：规划节点最多拆出五个子查询，LangGraph 通过 `Send` 并行执行语义检索与局部信息抽取，最终节点汇总证据并生成答案。该 DAG 设计用于避免完全串行 Agent 循环造成的延迟累积。资源匹配结果在写回路径前必须通过真实 ID 集合校验，阻断模型引用不存在的制品。

### 4.4 工程可靠性

- 视频、播客和其他高延迟资源通过异步任务队列生成；
- 前端轮询或订阅任务状态，不与模型推理生命周期绑定；
- 任务记录保存状态、结果和错误信息，支持追踪与失败恢复；
- 高成本媒体生成设置用户确认门，形成 human-in-the-loop 控制；
- 模型能力通过统一配置层提供，可切换多家云端模型与本地部署方案；
- 终稿不虚构尚未实现的缓存、熔断、分布式调度或性能指标。

## 五、措辞策略

口播采用“机制—取舍—价值”三段式表达。例如：

> 系统没有把所有记忆都塞进同一个向量库。课程知识使用稠密向量完成语义召回；学习者状态则使用可解释的六维事实表示。这样既保留检索效率，也避免用户目标和易错点被压缩成无法审计的黑盒向量。

论文名称只在正文自然点名 Mem0 一次。Generative Agents、ReAct 和 LLMCompiler 作为稿末“不朗读的技术依据”，避免在有限时间内把演示变成论文综述。

## 六、明确禁止的夸大表述

- 不声称“完整复现 Mem0”或直接使用 Mem0 库；
- 不将 SurrealDB 图数据库等同于 GraphRAG；
- 不声称实现 DKT、BKT 或其他未经代码支持的知识追踪模型；
- 不把角色化模块描述为能够自由协商、辩论或自主涌现的智能体群；
- 不声称学习路径会在无用户操作的情况下自动重规划；
- 不虚构论文基准、准确率、延迟提升、成本下降或线上用户规模；
- 不把结构化学习者画像错误描述为“个人向量”。
